## Smart Routing

```ts
// Complexity-based model routing
type ComplexityLevel = 
  | "trivial"   // Simple lookups → fast models
  | "simple"    // Single operations
  | "moderate"  // Multi-step tasks
  | "complex"   // Analysis & planning → powerful models  
  | "expert"    // Architecture decisions → best models

// Automatic classification based on:
const routingFactors = [
  "Query length and structure",
  "Keywords (create, analyze, optimize)",
  "Domain detection (GitHub, code, deploy)",
  "Multi-step indicators (and, then)"
]
```
